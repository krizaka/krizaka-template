# **Product** — agent contract

Started from `krizaka/krizaka-template` (target `mobile`). The governance of the family is **krizaka-com's AGENTS.md** — read it, do not copy it here.

- Use `@krizaka/ui/native` for all UI components and `@krizaka/tokens/native` for colours; no hardcoded hex values anywhere.
- Every user-facing string lives in `src/i18n/en.json` and `src/i18n/fr.json` with matching keys; both languages are always present.
- Tests with every change: render tests with `jest-expo` + `@testing-library/react-native` for every screen and navigator change.
- The skeleton is minimal by design: add screens, navigation routes and i18n keys as the product grows; keep it under 250 lines per `.tsx` file.
- Shared things stay shared: the CI pipeline is `krizaka/.github` reusable workflows (`ci.yml` only wires it); `@krizaka/*` packages are the single source of truth for UI, tokens, icons and i18n.
- Native folders (`ios/`, `android/`) are generated by `npx expo prebuild`; never commit them.
